This is the source code of the RELOAD algorithm for Elliptic Localization associated with our IEEE TSP paper:

K. Hu, W. Xiong and H. C. So, "RELOAD: Robust Elliptic Localization via low-rank structure of Observation and Adjoint Distance matrices," in IEEE Transactions on Signal Processing, doi: 10.1109/TSP.2026.3733624.

Please cite our paper if you use our codes.
